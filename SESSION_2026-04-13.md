## Problems Encountered During Deployment

### 1. Partial file replacement on router failed

- Replacing only a few files on an older router installation caused menu/runtime mismatches such as:
  - `comp_box: not found`
  - `btm_box: not found`
- Cause:
  - target router version was older than the local forked script layer
  - partial replacement was not enough

### 2. Mihomo local HY2 generation produced a usable manual proxy, but transparent routing failed

- Manual proxy on LAN devices through `192.168.100.1:7890` worked.
- Router-local curl via `127.0.0.1:7890` also worked.
- Transparent routing for client devices did not behave like subscription-generated configs.

Initial implementation issue:

- Mihomo HY2 local generation first used a hand-written minimal final YAML config.
- This diverged from ShellCrash's native provider/template generation path.
- Result:
  - single-node config could be valid enough for manual proxy use
  - but behavior under ShellCrash's routing/template system differed from subscription/provider generation

### 3. Sing-box path had the same structural risk

- Sing-box local HY2 generation originally wrote a direct final JSON config.
- That meant HY2 single-node and subscription/provider paths did not share the same generation pipeline.

## Code Changes Made

### Shared URI parsing

Refactored `scripts/libs/hy2_uri.sh`:

- extracted reusable Hysteria2 URI parsing
- kept support for:
  - password
  - server / port
  - `sni` / `peer`
  - `alpn`
  - `obfs`
  - `obfs-password`
  - `up` / `down`
  - `insecure`

### Mihomo path

Changed Mihomo local HY2 generation to:

1. generate a local provider file under `providers/`
2. call native ShellCrash Clash/Mihomo provider generation logic

This makes Mihomo HY2 single-node behavior align with normal subscription/provider generation.

### Sing-box path

Changed Sing-box local HY2 generation to:

1. prefer native provider/template generation using a local provider input file
2. fall back to the original direct JSON generation if provider-based generation fails

This keeps compatibility while moving behavior closer to the native ShellCrash provider path.
